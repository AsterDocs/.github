<h1 align="center">Aster Docs</h1>

<p align="center">Beautiful, accessible API documentation, straight from your source code.</p>

Aster Docs turns the comments in your source code into a static site that people enjoy reading. Your declarations and comments come through exactly as written, every overload and enum value gets its own link, search runs locally, and every page reads well without JavaScript, in eight light and dark themes. Your documentation keeps living in your source comments.

Aster is powered by **Calyx**, its documentation engine. Calyx reads your sources directly and produces one documented standard that Aster publishes, so there's no Doxygen to install and no XML in between. Doxygen-style and Markdown comments work as written, and an existing Doxyfile's settings can be imported. C++ is supported today, with more languages on the way.

**Aster Garden** comes with it: a local workspace for choosing a theme, checking contrast, adding your logo, writing guide chapters, seeing documentation coverage, and building, previewing and publishing your site, all on your own computer.

Aster Docs is in early development, and the first release is on its way.
