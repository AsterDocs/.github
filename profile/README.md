<h1 align="center">Aster Docs</h1>

<p align="center">Beautiful, accessible API documentation from Doxygen XML.</p>

Aster Docs turns the Doxygen XML of a C++ library into a static site that people enjoy reading. Your declarations and comments come through exactly as written, every overload and enum value gets its own link, search runs locally, and every page reads well without JavaScript, in eight light and dark themes. Your documentation keeps living in your source comments.

**Aster Garden** comes with it: a local workspace for choosing a theme, checking contrast, adding your logo, writing guide chapters, seeing documentation coverage, and building, previewing and publishing your site, all on your own computer.

Aster Docs is in early development, and the first release is on its way.

- Website: [aster.florist](https://aster.florist) (launching soon)
- npm: [`aster-docs`](https://www.npmjs.com/package/aster-docs) (coming soon)
