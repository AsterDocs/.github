<h1 align="center">Aster Docs</h1>

<p align="center">Beautiful, accessible documentation, straight from your source code.</p>

Your documentation lives in your source comments. We turn it into a fast, accessible static site
that people enjoy reading.

- **[Aster](https://github.com/AsterDocs/Aster)**: the site generator, with Aster Garden, a local
  workspace for themes, guides, coverage and publishing.
- **[Calyx](https://github.com/AsterDocs/Calyx)**: the engine that reads your code and comments
  into an open documentation standard. Doxygen-style and Markdown comments work as written.

```
your code and comments  →  Calyx  →  Aster  →  your docs site
```

Both are in early development and licensed under Apache-2.0. The first release is on its way:
[aster.florist](https://aster.florist) · [`aster-docs` on npm](https://www.npmjs.com/package/aster-docs)
